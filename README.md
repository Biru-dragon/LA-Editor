### Requirement
- [Python 3.10](https://www.python.org/downloads/)

### What is this
Simple arrows editor for the game [Logic Arrows on Steam](https://store.steampowered.com/app/4210250/Logic_Arrows/).

### How to use it
A simple `python editor.py`.

### Controls
- `CTRL + S` to save (save file created next to the script)
- `CTRL + O` to open the save file (the save file is always named `World.json`)
- Almost all controls work just as they do in-game
